the story

“I got a new case. It broke my power button. So I built the fix and gave it away.”

Taseen, who made TapOff

I put an acrylic case on my Pixel 7 and suddenly the power and volume buttons stopped pressing the way they used to. Turning the screen off became a fight.

Pixel has no double-tap to turn the screen off on the home screen. The Play Store has apps that do it, but they all keep an accessibility service running all the time, and the moment I turned one on, my banking app refused to open.

So I built TapOff. It works on the same idea, but it only switches accessibility on for the second you double-tap, turns the screen off, and switches it right back off. Building it wasn't free for me. Using it is free for you.

set it up

Five minutes, once

Install TapOff and give it one permission, on the phone with the free Shizuku app or from a computer. After that, you never think about it again.

No computer: install it and use Shizuku

  1. On the phone, download TapOff.apk and install it.
  2. Install Shizuku from the Play Store, open it and start it with Wireless debugging. It walks you through pairing on the phone itself; you need Wi-Fi.
  3. Open TapOff → Settings → Set up without a computer → Allow.

The permission stays, so you can remove Shizuku afterwards. Play Protect says "App blocked to protect your device"? Use the computer install below.

Or: install it from a computer

  1. On the phone: Settings → About phone → tap Build number 7 times, then Settings → System → Developer options → USB debugging on.
  2. On the computer, download TapOff.apk and Android platform-tools.
  3. Plug the phone in and allow the prompt on it.
  4. In the folder with TapOff.apk, run this. It installs TapOff and gives it its one permission:
adb install -r TapOff.apk && adb shell pm grant com.taseen.tapoff android.permission.WRITE_SECURE_SETTINGS

Turn USB debugging off again afterwards if you like; the permission stays.

Make TapOff your wallpaper

Open TapOff → Settings → Set TapOff as home wallpaper → choose Home screen and lock screen. Then pick any wallpaper you like inside the app. The double-tap works through the wallpaper.

Optional: brightness and volume sliders

Turn on Sliders in TapOff and allow Display over other apps. Then tap Set up back tap: Quick Tap → Open app → the gear → TapOff Sliders.

questions

Play Protect says "App blocked to protect your device"

Some phones (Google's fraud protection, on in countries like Pakistan and India) block installing any app with an accessibility service from a browser or file manager. Installing from a computer isn't blocked: use the computer install above, where adb install puts it on the phone.

Why does it need Shizuku or a computer once?

Switching an accessibility service on and off by itself needs a permission that apps can't give themselves; only Android's debugging tools can. Shizuku uses Wireless debugging on the phone to give it; a computer uses USB debugging. Without it, TapOff still works as a wallpaper app; the double-tap just won't turn the screen off.

Is it safe?

The code is open for anyone to read. TapOff reads nothing on your screen, has no accounts or analytics, and only goes online to download wallpapers.

Does it work on phones other than Pixels?

The home-screen double-tap works with launchers that pass taps on empty space to the wallpaper, which includes Pixel Launcher and most launchers built like it. Back tap uses Pixel's Quick Tap. Built and tested on a Pixel 7 running Android 17.

Does the brightness slider fight adaptive brightness?

No. It changes brightness the same way the Quick Settings slider does: adaptive brightness stays on and keeps the level you picked. In normal light Android caps brightness a little below full, so the very top of the slide may not get any brighter.
