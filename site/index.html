the story

“I got a new case. It broke my power button. So I built the fix and gave it away.”

Taseen, who made TapOff

I put an acrylic case on my Pixel 7 and suddenly the power and volume buttons stopped pressing the way they used to. Turning the screen off became a fight.

Pixel has no double-tap to turn the screen off on the home screen. The Play Store has apps that do it, but they all keep an accessibility service running all the time, and the moment I turned one on, my banking app refused to open.

So I built TapOff. It works on the same idea, but it only switches accessibility on for the second you double-tap, turns the screen off, and switches it right back off. Building it wasn't free for me. Using it is free for you.

under the hood

What happens when you double-tap

You tap twice

The TapOff wallpaper hears two taps on empty home-screen space.

Accessibility, briefly

TapOff switches its accessibility service on for about a second.

Fade to black

It fades the screen out and locks the phone, with no lock-screen flash.

Off again

The service switches itself off. Your bank apps never notice a thing.

set it up

Five minutes, once

The last step needs a computer for about a minute. After that, you never think about it again.

Install the APK

Download TapOff.apk on your phone and open it. Allow your browser to install apps when Android asks.

Make TapOff your wallpaper

Open TapOff → Settings → Set TapOff as home wallpaper → choose Home screen and lock screen. Then pick any wallpaper you like inside the app. The double-tap works through the wallpaper.

Give it one permission from a computer

  1. On the phone: Settings → About phone → tap Build number 7 times, then Settings → System → Developer options → USB debugging on.
  2. On the computer: install Android platform-tools, plug the phone in and allow the prompt.
  3. Run this, then turn USB debugging off again if you like:
adb shell pm grant com.taseen.tapoff android.permission.WRITE_SECURE_SETTINGS

questions

Why does it need a computer once?

Switching an accessibility service on and off by itself needs a permission that only a computer can grant. Without it, TapOff still works as a wallpaper app; the double-tap just won't turn the screen off.

Is it safe?

The code is open for anyone to read. TapOff reads nothing on your screen, has no accounts or analytics, and only goes online to download wallpapers.

Does it work on phones other than Pixels?

The home-screen double-tap works with launchers that pass taps on empty space to the wallpaper, which includes Pixel Launcher and most launchers built like it. The lock-screen switch uses a Pixel feature. Built and tested on a Pixel 7 running Android 17.
